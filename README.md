# AAFXX Angular Website

Angular 20 standalone-component frontend for the AAFXX forex education brand.

## Run

```bash
npm install
npm start
```

Open http://localhost:4200. Production build: `npm run build`.

## Included
- Responsive black-and-gold homepage
- Books and course catalogues (illustrative sample data)
- Interactive shopping cart (in-memory)
- Trading strategy overview
- Supplied achievement graphics gallery
- About and contact pages
- Student login modal (UI only)

## Before going live
Replace sample books, prices and descriptions with confirmed content. Integrate backend authentication, product/order APIs, a payment processor, file delivery, course progress and contact form submission. Verify achievement and performance claims, add a clear risk disclosure and legal pages. No real checkout or sign-in is implemented.
