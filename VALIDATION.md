# Validation — education and book marketing redesign

Validated locally on 22 October 2026 against the current `develop` implementation.

- `npm ci`: passed with the existing lockfile.
- Production Angular build with root base href: passed; approximately 303 kB raw / 82 kB estimated compressed initial payload.
- Actual `prerender:amplify` script: passed using `https://example.org` strictly as a local metadata fixture, not a configured deployment domain.
- SEO: unique titles/descriptions, one H1, canonical/social metadata, schema, robots and sitemap checks across 29 routes passed. Four academy aliases also receive static HTML with course canonicals.
- Browser functional checks: theme default/persistence; book search/topic filters; deep links and reload; course level/format filters and empty states; resource search; quiz feedback; journal download; unknown-route noindex page.
- Enquiry checks: selected book/course survives navigation and refresh; invalid form blocks action; real clipboard copy includes selection and message; denied clipboard gives error/fallback; downloaded enquiry contains selected title; messages never claim server delivery.
- Responsive browser sweep: 232 route/theme/viewport combinations (29 routes × dark/light × widths 320, 390, 768, 1440). One H1, no horizontal overflow, all images decode, no obsolete sandbox controls, and no JavaScript page errors.
- 37 internal link targets returned successful responses. Mobile navigation, keyboard skip link and reduced-motion behavior passed.
- Desktop and mobile homepage screenshots reviewed; catalogue, detail and article screenshots are generated by the browser suite.

- Automated WCAG 2.2 AA-tagged axe checks passed on eight representative pages in both themes (16 scans, zero violations). Text remains at full opacity during section reveals to maintain contrast.
- Amplify preview mode without `SITE_ORIGIN` and the 29-route preview SEO checks passed: noindex and no guessed canonicals or sitemap.
- The browser cache initially contained a zero-byte Chromium executable; the local packaged browser was re-extracted for validation. This was an environment issue, not a deployment-script change.

## Limits

No live enquiries, payments or external messages were sent. No confirmed contact address or delivery backend exists. The available alternative creates a local copy/download only. Product and programme facts remain unconfirmed and labelled accordingly. Automated accessibility checks are not a certification of full WCAG conformance. Local timing observations are not field Core Web Vitals. Live Amplify deployment, HTTP 404 rewrites, production origin and search indexing require host-side verification.
